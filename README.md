# Evidence Recorder

Public welcome and Android installation guide: https://abdylan.github.io/

Download the signed Android release from the website or GitHub Releases.
The current APK is version 0.8-release-policy (7.6 MB), with debugging disabled
and a dedicated release signing key. Android 11 or later is required.

Cloud access requires a connection code from the app owner. This repository
contains the website and public APK assets only. Recordings, device credentials
and release timers are managed separately.

Existing debug installations cannot update to the new release signing key in
place. Keep your existing app if recordings or uploads are pending, and contact
the owner before changing it.

To update the download, change the public APK URL and metadata in site-config.js.
Never store credentials, connection codes or signed URLs in this repository.
